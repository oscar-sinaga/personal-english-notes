## Proposed Workflow (Siklus Latihan Fleksibel 1.5 - 2 Jam)

Setiap sesi (merujuk pada silabus di atas) akan menggunakan alokasi waktu fleksibel **90 hingga 120 menit**:

### Tahap 0: Input & Pemahaman Konsep (Reading - 30 hingga 60 Menit)
- **Fleksibilitas:** Anda bebas menentukan durasi membaca mandiri sesuai *mood* dan tingkat kesulitan sub-bab hari itu.
- **Tugas:** Membaca bagian dari buku PDF untuk menyerap konsep teknis dan mengumpulkan *technical vocabulary* tingkat lanjut (C2).

### Tahap 1: Active Writing (20 Menit) - "The Technical Documentation"
- **Tugas:** Menulis ringkasan teknis pendek (2-3 paragraf) dalam bahasa Inggris dari apa yang baru dibaca, seolah sedang menulis *email update* untuk tim data di perusahaan.
- **Peran AI:** Saya bertindak sebagai *Editor* (mengoreksi *grammar*, meningkatkan tingkat profesionalisme *vocabulary* tanpa mengubah makna).
- **Output File:** `[Topik_X]/[YYYY-MM-DD_HH-MM]_Active_Writing.md`

### Tahap 2: Thinking & Circumlocution (20 Menit) - "The Concept Breakdown"
- **Tugas:** Menjelaskan istilah teknis sulit dari bab tersebut **tanpa** boleh menggunakan kata aslinya.
- **Peran AI:** Mengevaluasi *logic* dan naturalitas teknik *circumlocution* Anda.
- **Output File:** `[Topik_X]/[YYYY-MM-DD_HH-MM]_Circumlocution.md`

### Tahap 3: Verbal Output / Speaking (20 Menit) - "The Stakeholder Role-Play"
- **Tugas:** Simulasi *meeting* lisan atau ketik cepat. Saya berperan sebagai *Chief Risk Officer (CRO)* yang menantang pemahaman Anda mengenai konsep yang baru dibaca.
- **Peran AI:** Memberikan tekanan berupa *follow-up questions* dan mengevaluasi kelancaran argumen (*fluency* & *Lego Blocks*).
- **Output File:** `[Topik_X]/[YYYY-MM-DD_HH-MM]_Role_Play.md`

# Part 2: Personal English Tracker (Web App) Implementation Plan

Merespons permintaan Anda, kita akan membangun aplikasi web pendamping secara langsung. Ini **bukan overkill**, melainkan langkah *engineering* yang jenius untuk menjamin konsistensi belajar Anda.

## Goal
Membangun *standalone web application* berdesain premium untuk melacak progres belajar bahasa Inggris khusus untuk silabus *Credit Intelligence*.

## Proposed Tech Stack
- **Core:** React.js dengan *build tool* Vite (Sangat cepat dan modern).
- **Styling:** Vanilla CSS murni. Sesuai *best practice* desain modern, kita akan menggunakan *Dark Mode*, *Glassmorphism* (efek kaca tembus pandang), dan animasi mulus (*micro-animations*).
- **Data Storage:** `localStorage` (Berjalan 100% *offline* di browser Anda tanpa perlu *database server*).

## Key Features
1. **The Credit Intelligence Roadmap:** Visualisasi progres (berupa *progress bar* dan *checkbox*) untuk 7 Module dan seluruh *Chapter*-nya.
2. **The 3-Pillar Habit Timer:** *Stopwatch* khusus yang membagi sesi 60 menit menjadi 3 fase (20 menit *Writing*, 20 menit *Circumlocution*, 20 menit *Role-Play*).
3. **Log Generator:** Kolom teks terintegrasi tempat Anda mengetik ringkasan/jawaban. Setelah selesai, ada tombol "Download" yang otomatis membuat file `.md` dengan penamaan *timestamp* (contoh: `2026-06-16_14-30_Active_Writing.md`) untuk Anda simpan di folder IDE.

## User Review Required
> [!IMPORTANT]
> 1. **Penyimpanan File:** Karena batasan keamanan *browser*, aplikasi web tidak bisa otomatis menyimpan file langsung ke path `D:\...` tanpa izin. Solusi terbaiknya: Aplikasi akan menyediakan tombol **"Download .md"**, lalu Anda tinggal men-save file tersebut ke folder yang tepat. Apakah ini bisa diterima?
> 2. **Desain:** Saya akan mendesain UI-nya bernuansa "Deep Space Data Engineer" (Gelap elegan dengan aksen biru/ungu *neon*). Apakah Anda menyukai tema ini?
